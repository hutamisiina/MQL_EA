# Adaptive Breakout Basket EA

MetaTrader 5（MT5）向けの、複数ポジションをまとめて管理する実験的なExpert Advisor（EA）です。

買いと売りを組み合わせた疑似ストラドル／両建ての考え方をベースに、M1の直近高値・安値を更新した方向だけへポジションを追加し、バスケット全体の損益で決済します。

> [!WARNING]
> このEAは仮説検証用です。利益を保証するものではありません。v1.02の初期設定では固定金額による損切りは無効ですが、含み損バスケットの17分保有による損切りは有効です。最大ポジション数は実質的に制限しない値のため、必ずストラテジーテスターとデモ口座で検証し、ご自身の責任で使用してください。
> 証拠金の目安は、セント口座（通常口座の1/100）で2,000 JPY以上、0.01 lotを想定しています。通常口座では0.01 lotでも20万円以上を想定しています。

## 主な特徴

- 現在価格が直前の確定M1足数本の高値を上抜いた場合だけBUY
- 現在価格が直前の確定M1足数本の安値を下抜いた場合だけSELL
- 時間が経過しただけではポジションを追加しない
- 同方向の直近エントリーから一定距離以上離れた場合だけ追加
- 複数ポジションの合計損益を使ったバスケットトレーリング
- 買い・売りの偏りに応じてトレーリング幅を自動調整
- ヘッジ部分を `Close By` で相殺してから残りを決済
- 決済に失敗した場合の再試行処理
- 発注結果をサーバーのリターンコードまで確認
- MT5／VPS再起動後もトレーリングのピークと下限を復元
- 最古ポジションの保有時間によるバスケット損切り
- 保有ポジション数による任意のバスケット損切り
- 金曜23:59（JST）以降の週末新規エントリーを停止
- Magic Numberにより、このEAのポジションだけを管理

## 売買ロジックの概要

1. 直前の確定M1足を `InpBreakoutLookbackBars` 本読み、その区間の最高値と最安値を作ります。
2. 現在のBidが最高値を上抜いた場合はBUY、最安値を下抜いた場合はSELLの候補にします。
3. 同方向の直近エントリーから `InpMinEntryDistancePrice` 以上離れている場合だけ注文します。
4. 高値・安値を更新していないM1足では何も追加しません。ポジションがない場合も、最初のブレイクが発生するまで待機します。
5. バスケット全体の利益が開始額に達すると、利益のピークを追跡します。
6. 利益がトレーリング下限まで戻ると、全ポジションをまとめて決済します。

初期値の3本・80ポイントはXAUUSD M1向けの検証開始値であり、最適値ではありません。銘柄の桁数、スプレッド、ボラティリティに合わせてストラテジーテスターで調整してください。

## 導入方法

1. 最新版の [AdaptiveHedgeBasket_v1.02.mq5](Experts/AdaptiveHedgeBasket_v1.02.mq5) をダウンロードします。
2. MT5で「ファイル」→「データフォルダを開く」を選択します。
3. `MQL5/Experts` フォルダへ `.mq5` ファイルをコピーします。
4. MetaEditorでファイルを開き、コンパイルします。
5. MT5のナビゲータを更新し、EAを対象チャートへ適用します。
6. 自動売買を有効にします。

売買判定はM1データを使用します。また、BUYとSELLを同時保有するため、MT5のヘッジ口座が必要です。ネッティング口座では安全のため初期化を停止します。`Close By` 非対応の銘柄では通常決済へ切り替えます。

## 主なパラメータ

| パラメータ | 初期値 | 内容 |
|---|---:|---|
| `InpLots` | `0.01` | 1注文あたりのロット数 |
| `InpBreakoutLookbackBars` | `3` | 高値・安値更新の比較対象にする直前M1足の本数 |
| `InpBreakoutBufferPrice` | `0.0` | 直近高値・安値をどれだけ超えてからブレイクとするか（価格単位） |
| `InpMinEntryDistancePrice` | `0.80` | 同方向の直近エントリーから次の追加までに必要な最低価格差 |
| `InpTrailStartProfit` | `1.0` | バスケットトレーリング開始利益（口座通貨）。初期値は0.01 lot基準で、`InpLots` に応じて概ね比例調整する |
| `InpTrailFixedDistance` | `0.3` | 利益ピークからの固定トレーリング幅。`InpTrailStartProfit` 変更時に合わせて調整する（初期目安は開始利益の30%） |
| `InpTrailPercent` | `20.0` | 利益ピークに対するトレーリング幅（%） |
| `InpBasketProfitMoney` | `1.0` | トレーリング無効時だけ使用する固定利益確定額。初期値は0.01 lot基準 |
| `InpBasketLossMoney` | `0.0` | バスケット損失上限。`0`は無効 |
| `InpUseHoldingTimeStop` | `true` | 含み損バスケットの保有時間による損切りを有効化 |
| `InpMaxHoldingMinutes` | `17` | 最古ポジションから損切りまでの最大保有時間（分） |
| `InpUsePositionCountStop` | `false` | 含み損バスケットの保有本数による損切りを有効化 |
| `InpPositionCountStop` | `100` | 保有本数損切りを発動するポジション数 |
| `InpMaxPositions` | `9999999` | このEAが保有できる最大ポジション数。初期値は実質的に上限を設けない設定 |
| `InpUseWeekendEntryGuard` | `true` | 金曜23:59（JST）から日曜23:59（JST）まで新規エントリーを停止 |
| `InpUseCloseByForHedge` | `true` | 両建て部分をClose Byで相殺する |

`InpBasketProfitMoney` は、`InpUseBasketTrailing=false` の場合のみ固定利益確定として使用されます。`InpLots` を変更する場合は、`InpTrailStartProfit` と同様に調整してください。

## 使用前に必ず確認すること

- `InpBasketLossMoney` に許容できる損失上限を設定する
- 時間・保有本数の損切りは、条件到達時に含み損の場合のみ全ポジションを決済する
- 週末ガード中も既存ポジションの利確・損切り・決済再試行は継続する
- `InpMaxPositions` を口座資金に合わせて制限する
- ロット数、スプレッド、スワップ、証拠金維持率を確認する
- 利用するブローカーの銘柄名・契約サイズ・最小ロットを確認する
- 長期間・複数相場環境でバックテストする
- デモ口座でフォワードテストする

相場急変、窓開け、スリッページ、通信障害などにより、設定した金額どおりに決済できない場合があります。
